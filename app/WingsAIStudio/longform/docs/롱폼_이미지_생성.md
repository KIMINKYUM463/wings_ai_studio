# 롱폼: 이미지 생성 동작 정리

롱폼(`app/WingsAIStudio/longform`)에서 이미지는 크게 **① 문장(라인) 단위**와 **② 씬·장면 단위** 두 감으로 생성됩니다. 공통으로 **영어 프롬프트**를 만든 뒤 **Replicate**에서 이미지 URL을 받습니다.

---

## 1. 전체 흐름 요약

| 구분 | 프롬프트 생성 | 이미지 생성 호출 |
|------|----------------|------------------|
| **문장 리스트** (`scriptLines`) | 서버 `POST /api/generate-image` → `generateImagePrompt` (`actions.ts`) | 같은 API 내부에서 `generateImageWithReplicate` (**모델·스타일 인자 없음**, 아래 주의) |
| **씬/장면** (`decomposedScenes` + `[장면 N]` 블록) | `generateSingleSceneImagePrompts` (`scene-prompt-actions.ts`) | 클라이언트에서 `generateImageWithReplicate(..., imageStyle, …, imageModel)` 직접 호출 |
| **자동화 파이프라인** | 씬별 `generateSingleSceneImagePrompts` → 이후 `generateImageWithReplicate`와 동일 | 사용자가 고른 `imageModel`·`imageStyle` 전달 |

---

## 2. 문장(라인) 단위 이미지

### 진입점

- `page.tsx` → `handleGenerateImagesForLines`
- 각 문장마다 `fetch("/api/generate-image", { ... })`

### API: `app/api/generate-image/route.ts`

1. **입력**  
   - `scriptText` (해당 문장), `openaiApiKey`, `replicateApiKey`  
   - `category` (기본 `health`), `historyStyle` (**= UI의 `imageStyle`**), `topic`, 선택적 `characterAnchor` / `backgroundStyle` / `renderingStyle`  
   - `customPrompt`가 있으면 프롬프트 생성을 건너뛰고 사용

2. **프롬프트**  
   - `generateImagePrompt(...)` (`actions.ts`)  
   - 내부에서 **인물 타입**(korean / foreign / none), **시대** 등을 `gpt-4o-mini`로 추출한 뒤, 카테고리·`historyStyle`(스타일)에 맞춰 **한 줄의 영어 이미지 프롬프트**를 구성합니다.  
   - 스타일별 분기는 `historyStyle` 값에 따라 매우 길게 정의되어 있습니다 (실사화, 애니메이션2, 그래픽 노블, 다크판타지 등).

3. **후처리**  
   - `16:9`·`cinematic composition` 등이 없으면 문구 추가  
   - `aspectRatio`: 프롬프트에 `9:16`이 있으면 세로, 아니면 `16:9`

4. **Replicate 호출 (중요)**  
   - 현재 라우트는 `generateImageWithReplicate(prompt, replicateApiKey, aspectRatio)` **만** 호출합니다.  
   - **`imageStyle` / `selectedModel`을 넘기지 않습니다.**  
   - 따라서 `generateImageWithReplicate` 내부 기준으로는 `selectedModel`도 없고 `imageStyle`도 `stickman-animation`이 아니므로, **기본 모델은 `black-forest-labs/flux-pro`** 쪽 로직으로 동작합니다 (스틱맨 전용 `hidream` 자동 선택은 이 경로에서는 적용되지 않음).

5. **일관성 보조 (클라이언트)**  
   - 첫 장 성공 후 `extractCharacterAnchor`, 실사/애니메이션에 따라 `extractBackgroundAndRenderingStyle`로 다음 문장 프롬프트에 넘길 앵커·스타일을 쌓습니다.

### 공통 스타일 프롬프트

- `generateCommonStylePrompt` 호출은 **주석 처리**되어 있어, 라인 모드에서는 `commonStylePrompt`가 실질적으로 쓰이지 않습니다.

## 3. 씬·장면 단위 이미지

### 입력 대본 형식

- 장면 분해 결과 텍스트에서 **씬 블록**(`씬 1`, `씬 2`, …)과 **`[장면 N]`** 마커로 구간이 나뉩니다.  
- `generateSingleSceneImagePrompts`가 정규식으로 `[장면 N]`별 한국어 본문을 뽑습니다.

### 프롬프트 생성: `scene-prompt-actions.ts`

| 항목 | 내용 |
|------|------|
| **1차 모델** | OpenAI **`gpt-4o-mini`** (`/v1/chat/completions`), `max_tokens` 4000, `temperature` 0.7 |
| **실패 시** | HTTP 429 등 Rate limit이면 **`gemini-2.5-flash`** (`/api/gemini/generate-content`)로 폴백 |
| **시스템 프롬프트** | 장면별 **영어 이미지 프롬프트** 생성 규칙: 인물 일관성, **텍스트 금지**(no text/letters/words…), 스타일별 제약(애니메이션2=스틱맨 금지, 스틱맨=동일 캐릭터, 실사화+한국=Korean 배경 구분 등) |
| **유저 프롬프트** | 씬 번호, 각 `[장면 N]` 텍스트, `imageStyle`, 선택 `historicalContext` / `customStylePrompt`, 실사화 시 `realisticCharacterType` 안내 |
| **파싱** | 응답 형식 `장면 N: [시각화 지시(한국어)]` 다음 줄에 **영어 프롬프트**; 정규식으로 추출, 실패 시 완화 패턴 |

### 프롬프트 후처리 (같은 파일)

- `historicalContext`가 있으면 프롬프트에 병합  
- **`stickman-animation`**: 씬1 이후 동일 스틱맨 참조, 강한 스틱맨 전용 문구·부정 키워드 정리  
- **`realistic` / `realistic2`**: 카툰/스틱맨 키워드 제거, hyperrealistic/8K/DSLR 베이스 문구, 한국인/외국인 타입에 따른 키워드  
- **`animation2`**: stickman 관련 표현 제거·`stylized cartoon character` 치환, 플랫 벡터 카툰 스타일 블록 추가  
- (파일 후반부에 `animation3`, `semi-realistic-animation` 등 동일 계열 처리 이어짐)  
- 한글 잔여 시 정규식으로 제거  
- 텍스트 제외 구문이 없으면 `no text, no letters, ...` 추가  

### 이미지 생성: `generateImageWithReplicate` (`actions.ts`)

씬 UI/자동화에서는 다음 인자로 호출됩니다.

- `prompt`, `replicateApiKey`, **`"16:9"`**, **`imageStyle`**, `sceneDescription`(보통 `undefined`), **`imageModel`**

#### 모델 선택 로직

1. **`selectedModel`(= UI `imageModel`)이 있으면 그 모델 사용**  
   - 선택지 타입: `"prunaai/hidream-l1-fast"` | `"black-forest-labs/flux-schnell"` | `"google/imagen-4-fast"` (코드상 `flux-pro`도 허용)
2. `selectedModel`이 없고 **`imageStyle === "stickman-animation"`** 이면 **`prunaai/hidream-l1-fast`**
3. 그 외 기본 **`black-forest-labs/flux-pro`**

#### Replicate 입력 요약

| 모델 | 주요 input |
|------|------------|
| **hidream-l1-fast** | `prompt`, **width 1360, height 768**, 긴 `negative_prompt`, `num_inference_steps: 16`, `image_format: png` |
| **google/imagen-4-fast** | `prompt`, `aspect_ratio: "16:9"`, `num_inference_steps: 4`, `output_format: png` |
| **flux-schnell / flux-pro** | `prompt`, **width 1360, height 768**, `output_format: png`, `output_quality: 90`, 실사화 시 `negative_prompt`(텍스트·인물 불일치 등) |

#### 프롬프트 보정 (Replicate 직전)

- **`animation2`**: stickman 계열 단어를 `stylized cartoon character` 등으로 치환  
- **`realistic` / `realistic2`**: subtitle/caption 등 텍스트 관련 단어 제거  
- **공통**: `no text` 계열이 없으면 실사는 강화 문구, 그 외는 짧은 문구 추가  

#### 폴링·폴백

- 예측 `processing`이면 **2초 간격, 최대 120회** 폴링  
- **404/422** 시 `generateImageWithStableDiffusion` (**SDXL** 고정 버전) 시도  

---

## 4. UI 상태와 스타일 (`page.tsx`)

- **`imageStyle`**: 예) `stickman-animation`, `realistic`, `realistic2`, `animation2`, `animation3`, `semi-realistic-animation`, `vintage-illustration`, `dark-fantasy-concept`, `animation` 등  
- **`imageModel`**: `prunaai/hidream-l1-fast`, `black-forest-labs/flux-schnell`, `google/imagen-4-fast` (씬 생성 경로에서 우선 적용)  
- **`realisticCharacterType`**: `korean` | `foreign` | `none` | `null` — 실사화 씬 프롬프트에 한국/서양 구분 힌트로 사용  

---

## 5. 시대적 배경 (자동화·씬)

- `extractHistoricalContext(topic, script, openaiApiKey)` (`scene-prompt-actions.ts`): 주제/대본 일부를 **`gpt-4o-mini`**로 요약해 영어 한 줄(시대)로 만듦.  
- 자동화에서 씬 프롬프트 생성 시 `historicalContext`로 넘겨 장면 프롬프트에 반영합니다.

## 6. 필요한 API 키

| 용도 | 키 |
|------|-----|
| 라인 프롬프트 / 씬 프롬프트(기본) | **OpenAI** |
| 씬 프롬프트 폴백 | **Gemini** (Rate limit 시, `getEnvApiKey("gemini")`) |
| 이미지 픽셀 생성 | **Replicate** |

## 8. 한 줄 요약

- **씬 모드**: OpenAI(→필요 시 Gemini)로 **장면별 영어 프롬프트**를 만들고, UI에서 고른 **Replicate 모델**로 **1360×768 또는 Imagen 16:9** 등 설정에 맞춰 생성합니다.  
- **문장 모드**: 서버에서 **`generateImagePrompt` + Replicate**이며, 현재 API는 **모델을 쿼리 파라미터로 넘기지 않아** 기본적으로 **Flux Pro 계열** 동작에 가깝습니다. 스타일은 프롬프트(`historyStyle`) 쪽에 주로 반영됩니다.
