# 롱폼 · 썸네일 생성 기능 명세

**위치:** `app/WingsAIStudio/longform`  
**핵심 파일:** `page.tsx`(UI·단계), `actions.ts`(비즈니스 로직)

롱폼 썸네일은 **① 썸네일용 문구(텍스트)** 생성과 **② 이미지(URL)** 생성으로 나뉜다. 둘 다 선택적으로 사용할 수 있으며, 최종 이미지는 **Replicate `google/nano-banana-pro`** 로 만든다.

---

## 1. 기능 한눈에 보기

| 단계 | 목적 | 주요 함수·호출 |
|------|------|----------------|
| **썸네일 문구** | 대본 기준 짧은 카피 2줄(JSON) | `generateThumbnailText` → OpenAI `gpt-4o-mini` |
| **벤치마킹 분석**(선택) | 참조 썸네일 이미지 스타일을 영문 서술로 추출 | `analyzeThumbnailStyle`(비공개) → GPT-4o 비전 |
| **AI 썸네일 이미지** | 16:9 유튜브 썸네일 이미지 URL | `generateAIThumbnail` → Replicate 예측 API |

## 2. UI 진입점 (`page.tsx`)

### 2.1 썸네일 텍스트만 생성 (`handleThumbnailGeneration`)

- **조건:** `script` 존재.
- **동작:** `generateThumbnailText(script, undefined, getApiKey())` 호출.
- **결과 처리:** 반환값이 `{ line1, line2 }` 객체면 두 줄을 배열로 합쳐 `thumbnailText` 상태에 저장. (타입 상 문자열로 오는 레거시 분기도 처리.)

```5607:5639:app/WingsAIStudio/longform/page.tsx
  const handleThumbnailGeneration = async () => {
    if (!script) {
      alert("먼저 대본을 생성해주세요.")
      return
    }

    setIsGeneratingThumbnail(true)
    try {
      console.log("[v0] 썸네일 텍스트 생성 요청 시작")
      const result: any = await generateThumbnailText(script, undefined, getApiKey())
      
      // 결과가 문자열인 경우 (actions.tsx)와 객체인 경우 (actions.ts) 모두 처리
      let lines: string[] = []
      
      if (typeof result === "string") {
        // 문자열인 경우 줄바꿈으로 분리
        lines = result
          .split("\n")
          .map((line: string) => line.trim())
          .filter((line: string) => line.length > 0)
          .slice(0, 4)
      } else if (result && typeof result === "object" && "line1" in result) {
        // 객체인 경우 line1, line2 사용
        lines = [result.line1, result.line2]
          .filter((line: string) => line && line.trim())
          .slice(0, 4)
      }

      if (lines.length === 0) {
        throw new Error("생성된 텍스트가 없습니다.")
      }

      setThumbnailText(lines)
```

사용자가 이 줄들을 바탕으로 **커스텀 문구**(`thumbnailCustomText`)를 채우거나 편집한 뒤, 아래 AI 썸네일 생성에 넘긴다.

### 2.2 AI 썸네일 이미지 생성 (`handleAIGenerateThumbnail`)

- **주제 `topic`:** `selectedTopic`이 없으면 `extractTopicFromScript`로 추출하거나, 대본 앞 100자·50자로 잘라 사용.
- **필수 키:** `replicate_api_key` (`getApiKey`).
- **선택 정보:**
  - **스타일:** `thumbnailStyle`(실사/애니) 또는 미선택 시 `imageStyle`(stickman·realistic 등에 대응하는 영문 스타일 블록).
  - **문구:** `thumbnailCustomText` → `generateAIThumbnail`의 `customText`.
  - **캐릭터:** 첫 씬 이미지 프롬프트에서 정규식으로 짧게 뽑은 `characterDescription`.
  - **문구 없이:** `thumbnailWithoutText` → 시각만(텍스트 금지 강화).
  - **벤치마크:** `analyzedBenchmarkStyle`이 있으면 **URL(`benchmarkThumbnailUrl`)은 전달하지 않음**; 없을 때만 URL로 서버 측 분석을 시도할 수 있음.

## 3. `generateThumbnailText` — 썸네일 문구

**파일:** `actions.ts` (약 `4272`~`4332`행)

| 항목 | 내용 |
|------|------|
| API | `POST https://api.openai.com/v1/chat/completions` |
| 모델 | `gpt-4o-mini` |
| 키 | 인자 또는 `GPT_API_KEY` / `OPENAI_API_KEY` / `CHATGPT_API_KEY` |

**System**

```text
당신은 썸네일 텍스트 생성 전문가입니다. 대본을 분석하여 썸네일에 적합한 짧고 임팩트 있는 텍스트 2줄을 생성해주세요.
```

**User (템플릿)**

- 대본 앞 **2000자**
- 선택 시 `제목: ...`
- 요청: 줄당 **5~10자 내외**, JSON `{"line1":"...","line2":"..."}`

**후처리:** 응답에서 `{...}` JSON을 정규식으로 잡아 `JSON.parse`. 실패·예외 시 `"첫 줄"` / `"둘째 줄"` 등 기본값.

전문은 저장소에서 아래 구간을 보면 된다.

```4272:4331:app/WingsAIStudio/longform/actions.ts
export async function generateThumbnailText(
  script: string,
  title?: string,
  apiKey?: string
): Promise<{ line1: string; line2: string }> {
  const GPT_API_KEY = apiKey || process.env.GPT_API_KEY || process.env.OPENAI_API_KEY || process.env.CHATGPT_API_KEY

  if (!GPT_API_KEY) {
    throw new Error("GPT API 키가 설정되지 않았습니다.")
  }

  try {
    const response = await fetch("https://api.openai.com/v1/chat/completions", {
      method: "POST",
      headers: {
        Authorization: `Bearer ${GPT_API_KEY}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        model: "gpt-4o-mini",
        messages: [
          {
            role: "system",
            content: "당신은 썸네일 텍스트 생성 전문가입니다. 대본을 분석하여 썸네일에 적합한 짧고 임팩트 있는 텍스트 2줄을 생성해주세요.",
          },
          {
            role: "user",
            content: `대본:\n${script.substring(0, 2000)}\n${title ? `제목: ${title}` : ""}\n\n위 대본을 분석하여 썸네일용 텍스트 2줄을 생성해주세요. 각 줄은 5-10자 내외로 작성해주세요. JSON 형식으로 {"line1": "첫 줄", "line2": "둘째 줄"}로 응답해주세요.`,
          },
        ],
        max_tokens: 200,
        temperature: 0.8,
      }),
    })
    // ... 파싱 및 폴백
```

## 4. `analyzeThumbnailStyle` — 벤치마크 이미지 분석

**파일:** `actions.ts` (약 `4790`~`4898`행), **`export` 아님**(내부 헬퍼).

- 입력: 이미지 **URL** `thumbnailImageUrl`, OpenAI 키.
- 이미지를 `fetch` → `blob` → base64 → **`gpt-4o`** 멀티모달 user 메시지(텍스트 지시 + `image_url`).
- 출력: 영어로 **레이아웃·텍스트 위치·색·타이포·전체 스타일** 등을 길게 서술. 이 문자열이 `generateAIThumbnail`에 **`analyzedBenchmarkStyle`** 또는 내부 `benchmarkStylePrompt`로 들어간다.

벤치마크가 있으면 프롬프트의 **최우선 지시**는 “이 분석 결과를 그대로 따르되 주제·문구만 바꿔라” 쪽으로 여러 번 강조되며, `withoutText`이면 앞에 `NO TEXT...` 전치(문구 금지)가 붙는 분기가 있다.

## 5. `generateAIThumbnail` — 이미지 생성

**파일:** `actions.ts` (약 `4900`~`5838`행)  
**시그니처 요약:**

```text
generateAIThumbnail(
  topic,
  replicateApiKey,
  imageStyle?,           // stickman-animation, realistic, realistic2, animation2, animation3 등
  customText?,           // UI: thumbnailCustomText
  customStylePrompt?,    // UI: thumbnailStylePrompt 또는 customStylePrompt
  characterDescription?,
  withoutText?,          // true면 텍스트 완전 금지 프롬프트
  benchmarkThumbnailUrl?, // 분석 안 했을 때 분석용 URL
  openaiApiKey?,         // 벤치 URL 분석용
  analyzedBenchmarkStyle? // 이미 분석된 영문 스타일 블록(최우선)
)
```

### 5.1 프롬프트 분기 (개념도)

```text
analyzedBenchmarkStyle 있음?
  → 예: "BENCHMARK THUMBNAIL ANALYSIS" 블록 + topic + textContent(customText 또는 topic)
        + 16:9, 벤치 레이아웃/색/타이포 따르라는 다수 지시
        → (여러 단계에서 동일 구조로 prompt 재확인·교체 — 구현상 중복 로직 다수)

  → 아니오 + benchmarkStylePrompt(URL 분석 결과) 있음?
        → 유사하게 벤치 블록 + topic

  → 아니오
        → withoutText?
              → 예: 순수 비주얼만, NO TEXT 반복, negative_prompt 길게
              → 아니오: 기본 유튜브 썸네일 문구 + topic (+ customText 반영)
        → (벤치 없을 때) imageStyle → stylePrompt(스틱맨·실사·그래픽노블 등 영문 태그)를 끝에 합침
        → 캐릭터 설명 있으면 본문에 포함(비- withoutText 경로에서 basePrompt 확장)

최종적으로 withoutText면 prompt 앞에 "NO TEXT..." 전치 추가
(analyzedBenchmarkStyle와 충돌 시 구현상 벤치 재주입 로직이 있음 — 디버깅용 로그 다수)
```

### 5.2 Replicate 요청

| 필드 | 값 |
|------|-----|
| URL | `POST https://api.replicate.com/v1/models/google/nano-banana-pro/predictions` |
| 헤더 | `Authorization: Token {replicateApiKey}` ※ Bearer가 아님 |
| `input.prompt` | 위에서 조합한 최종 문자열 |
| `input.aspect_ratio` | `"16:9"` |
| `input.output_format` | `"png"` |
| `input.negative_prompt` | `withoutText` 분기에서만 설정(텍스트 관련 키워드 대량) |

### 5.3 완료 대기

- 예측 `id`로 `GET /v1/predictions/{id}` **5초 간격** 폴링, 최대 **60회**(약 5분).
- `succeeded` 시 `output`이 문자열·배열·`url` 객체 등 변형을 처리해 **이미지 URL 문자열** 반환.

## 8. 구현 상 주의

- **`actions.ts`와 `actions.tsx`가 함께 존재**하면 빌드/번들 해석에 따라 한쪽만 쓰일 수 있다. 수정 시 **실제 import 대상 파일**을 확인할 것.
- `generateAIThumbnail`은 벤치마크 포함 여부를 보장하기 위해 **동일한 프롬프트 조립이 여러 번 반복**된다. 동작 이해 시 “`analyzedBenchmarkStyle`이 있으면 최종 `requestBody.input.prompt`가 벤치 기반으로 고정된다” 수준으로 파악하면 된다.
