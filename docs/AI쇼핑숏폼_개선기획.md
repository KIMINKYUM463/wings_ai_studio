# AI 쇼핑 숏폼 개선 기획 (2026-11-16)

쿠팡 상품만 있고 영상 소스가 없을 때 쓰는 기능. 목표는 **리믹스 쇼핑숏폼 수준의 영상 품질**과 **고급스러운 제작 화면**.

## 1. 지금 문제 (조사 결과)

### 영상 품질
| 문제 | 위치 | 영향 |
|---|---|---|
| AI 영상이 720p(Wan 경로는 약 480p)로 만들어져 1080p로 늘려 씀, 카메라 고정 | actions.ts:3389-3442, 1720-1737 | 흐릿하고 정지 화면 같음 |
| 장면이 3개로 고정, 장면당 3~12초 | actions.ts:2629, page.tsx:790 | 슬라이드쇼 느낌, 컷이 적음 |

| TTS 앞뒤·중간 무음 제거 없음 | — | 늘어지는 템포 |

### 화면
- 거의 모든 화면이 page.tsx 한 파일(12,500줄)에 들어 있음.
- 앱 전체 색 반전(light-remap) 때문에 코드상 주황색이 화면에서는 파란색으로 보이고, 색이 뒤섞임.
- 홈은 "9단계"라고 쓰고 단계 칩은 8개. "최근" 배지는 그냥 첫 카드. 7일 뒤 자동 삭제 안내 없음.
- 편집툴의 자르기·나누기·실행 취소 버튼이 늘 꺼져 있음. 자막 템플릿 선택도 꺼져 있음.
- 오류는 alert() 팝업으로 띄움(108곳). 글자 9~10px.

## 2. 개선안

### A. 디자인 (리믹스 스튜디오와 같은 밝은 고급 톤)
- 펄 화이트 바탕(#f5f6fa), 흰 카드, 잉크 글자(#0e1016), 울트라마린 포인트(#2f3beb). 반전 영역은 `light-keep`으로 직접 색 지정.
- **홈 (완료)**: 큰 헤드라인, 9단계 흐름, "이어서 작업하기" 큰 카드(상품 사진·진행 막대), 프로젝트 카드(표지 사진·D-n 자동 삭제·진행 막대·⋯ 메뉴), 새 프로젝트 창 리디자인.
- **단계 틀 (완료)**: 왼쪽 단계 메뉴(진행 막대·지금 단계 검정 강조), 위쪽 바(N단계 / 9단계, 이전·다음 단계), 흰 단계 카드.
- **단계 내용 (진행 중)**: 편집툴(휴대폰 미리보기, 차분한 타임라인, 자막 디자인 정리, 꺼진 버튼 정리), 이미지·음성·썸네일·키워드 단계.

### B. 영상 품질 (리믹스 마무리 처리 재사용) — 진행 중
새 서버 렌더 엔진 `lib/ai-shopping-render/engine.ts` + `/api/ai-shopping/render-pro`:
1. 장면 수 제한 없음. 장면이 자리보다 짧으면 멈추지 않고 자연스럽게 이어 채움, 이미지는 천천히 움직임.
2. 자막: 리믹스 자막(숫자·핵심 단어 강조색, 팝 모션, 스티커).
3. 모션: 핵심 확대샷, 장면 전환 줌·빛, 제품 강조 스냅 줌.
4. 소리: 배경음악 루프·페이드·나레이션 덕킹, 문장·전환에 맞춘 효과음 자동 배치.
5. 광고·AI 표기(쿠팡 파트너스·AI 생성 영상 포함), 썸네일 첫 프레임.
6. 화질: 1080×1920, CRF 20, 한 번만 인코딩.
편집 단계에 "고품질 렌더링"을 기본 버튼으로, 기존 방식은 보조로 남김.
