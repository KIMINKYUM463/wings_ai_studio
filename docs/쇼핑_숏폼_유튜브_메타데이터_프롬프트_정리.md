# 쇼핑 숏폼 · 제목 / 설명 / 태그가 나오는 방식 (프롬프트 정리)

**구현:** `app/WingsAIStudioShotForm/shopping/actions.ts` → `generateYouTubeMetadata`  
**모델:** `gpt-4o-mini`  
**응답 형식:** `response_format: { type: "json_object" }` — 모델은 **하나의 JSON 객체**만 출력한다.

---

## 1. 전체 흐름

```text
입력 3가지 (함수 인자)
  ├─ productName      → user 메시지 "제품명:"
  ├─ productDescription → user 메시지 "제품 설명:"
  └─ script           → user 메시지 "영상 대본:"
         ↓
  system 메시지: 역할·규칙·출력 JSON 스키마 고정
         ↓
  OpenAI Chat Completions
         ↓
  응답 문자열 content (JSON)
         ↓
  JSON.parse → { title, description, tags }
         ↓
  필드별 보정·폴백 (아래 §5)
```

**제목·설명·태그**는 모두 **같은 한 번의 완성 요청**에서 나온다. 별도 API 호출이 없다.

---

## 2. System 프롬프트 (원문)

코드에 백틱 문자열으로 들어 있는 내용과 동일하다.

```text
당신은 유튜브 쇼츠 영상 메타데이터 작성 전문가입니다. 제품 홍보 영상에 최적화된 제목, 설명, 태그를 생성해주세요.

규칙:
1. 제목: 50자 이내, 클릭을 유도하는 강력한 후킹 문구, 이모지 사용 가능
2. 설명: 500자 이내, 제품 특징과 장점을 간결하게, 관련 링크 공간 확보
3. 태그: 10-15개, 제품명, 카테고리, 키워드 포함, 쉼표로 구분

JSON 형식으로 응답:
{
  "title": "제목",
  "description": "설명",
  "tags": ["태그1", "태그2", ...]
}
```

### 2.1 System이 하는 일 (요약)

| 출력 필드 | System에서 정한 제약 |
|-----------|---------------------|
| **title** | 50자 이내, 후킹, 이모지 가능 |
| **description** | 500자 이내, 특징·장점 간결, 링크 넣을 여지 |
| **tags** | 10~15개, 제품명·카테고리·키워드. 문구상 "쉼표로 구분"이나 **실제 스키마는 JSON 배열** |

---

## 3. User 프롬프트 (템플릿)

실제 전송 시 `${productName}`, `${productDescription}`, `${script}` 가 채워진다.

```text
제품명: ${productName}
제품 설명: ${productDescription}
영상 대본: ${script}

위 정보를 바탕으로 유튜브 쇼츠 영상용 제목, 설명, 태그를 생성해주세요.
```

**의미:** 모델은 위 세 덩어리만 보고, 쇼츠에 맞는 메타데이터를 한 번에 채운다.

---

## 4. API 옵션 (프롬프트와 같이 쓰는 설정)

| 옵션 | 값 | 역할 |
|------|-----|------|
| `model` | `gpt-4o-mini` | 생성 모델 |
| `max_tokens` | `500` | 출력 길이 상한 |
| `temperature` | `0.8` | 다양성(높을수록 변주 많음) |
| `response_format` | `{ type: "json_object" }` | **유효 JSON 한 덩어리**로만 답하게 유도 → `title` / `description` / `tags` 키 파싱 가능 |

---

## 5. 모델 출력 이후 코드가 하는 일 (필드별)

응답 `content`를 `JSON.parse` 한 뒤 `parsed`에서 꺼낸다.

### 5.1 제목 (`title`)

- 우선: `parsed.title`
- 없으면: `` `${productName} 추천!` ``
- API 전체 실패(catch) 시에도 동일 폴백 문자열

### 5.2 설명 (`description`)

- 우선: `parsed.description`
- 없으면: `` `${productDescription}\n\n${script}` `` (설명 + 대본 이어붙임)
- catch 시 동일

### 5.3 태그 (`tags`)

- 우선: `parsed.tags`가 **배열**이면 그대로 사용
- 배열이 아니고 **문자열**이면 `split(",")` 후 각 항목 `trim`
- 그마저 없으면 `[productName]`
- catch 시: `[productName, "쇼핑", "추천", "리뷰"]`

---

## 6. 참고: System 문구와 실제 형식

- 규칙 3번에 "쉼표로 구분"이라고 되어 있지만, **요구 JSON 스키마는 `tags` 배열**이다.  
- 코드는 배열을 우선하고, 혹시 문자열로 온 경우만 쉼표 분리로 처리한다.
