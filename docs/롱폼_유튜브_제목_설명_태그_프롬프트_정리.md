## 1. 사용자가 보는 흐름

1. **제목 후보 생성** — 버튼으로 `generateYouTubeTitles` 호출 → **최대 10개** 한글 제목이 리스트로 표시됩니다.
2. **제목 선택** — 카드 하나를 클릭하면 `selectedTitle`이 바뀌고, **같은 클릭 안에서** `generateYouTubeDescription`이 자동 호출됩니다.
3. **결과 표시** — 설명란(`description`), 고정댓글(`pinnedComment`), 첫 줄용 해시태그 문자열(`hashtags`), **업로드용 태그 배열**(`uploadTags`)이 한 번에 채워집니다.

수동으로 설명만 다시 만들려면 `handleDescriptionGeneration`으로 **대본 + 선택된 제목**이 있을 때 호출할 수 있습니다.

## 2. 제목 10개 — `generateYouTubeTitles`

| 항목 | 값 |
|------|-----|
| API | `POST https://api.openai.com/v1/chat/completions` |
| 모델 | `gpt-4o-mini` |
| `max_tokens` | `1000` |
| `temperature` | `0.9` |

### 2.1 System 프롬프트 (원문)

```text
당신은 유튜브 제목 생성 전문가입니다. 대본을 분석하여 클릭률이 높은 제목 10개를 생성해주세요.
```

### 2.2 User 프롬프트 (템플릿)

- `카테고리: ${category}`
- `대본:\n${script.substring(0, 2000)}`
- 지시: **유튜브 제목 10개**, **반드시 한글만**, 각 제목 **한 줄**

### 2.3 응답을 배열로 만드는 방법

모델 출력 전체를 **줄 단위**로 나눈 뒤, 정규식 `^\d+\.\s*(.+)$` 로 **번호 목록 형식**(예: `1. 제목`)만 골라 최대 10개까지 `string[]`로 만듭니다.  
하나도 못 찾으면 폴백으로 `["매력적인 제목 1", "매력적인 제목 2"]`를 반환합니다.

### 2.4 UI에서의 호출 (일반)

```5535:5536:app/WingsAIStudio/longform/page.tsx
      const titles = await generateYouTubeTitles(script, selectedCategory, apiKey)
      setGeneratedTitles(titles)
```

**참고:** 자동화 파이프라인(`runAutomationPipeline`)에서는 `generateYouTubeTitles(selectedTopic, scriptWithCTA, apiKey)`처럼 **첫 인자·둘째 인자 순서가 반대**라, 프롬프트상으로는 “카테고리” 자리에 긴 대본이, “대본” 자리에 주제 문자열이 들어갈 수 있습니다. 수동 UI와 동일 동작을 기대할 때는 순서를 맞추는 편이 안전합니다.

## 3. 설명·고정댓글·해시태그·업로드 태그 — `generateYouTubeDescription`

**한 번의 API 호출**로 네 가지가 모두 나옵니다. 입력으로 **선택된 제목**이 반드시 들어갑니다.

| 항목 | 값 |
|------|-----|
| API | 동상 `chat/completions` |
| 모델 | `gpt-4o-mini` |
| `max_tokens` | `2000` |
| `temperature` | `0.7` |

### 3.1 User 프롬프트 (템플릿)

```text
제목: ${title}
카테고리: ${category}
영상 길이: ${videoDurationMinutes}분   ← 값이 있을 때만 줄 추가

대본:
${script.substring(0, 3000)}

위 대본을 분석하여 유튜브 설명을 작성해주세요. 핵심 태그 3개는 첫 줄에만 포함하고, 마지막 부분에는 그 외 태그들만 포함하세요.
```

`scriptDuration`(UI)이 분 단위로 넘어가면 모델에게 **영상 길이(분)** 맥락을 줍니다.

### 3.2 System 프롬프트 — 생성 항목 요약

| 필드 | 역할 |
|------|------|
| **description** | 유튜브 설명란. 이모지 사용. **첫 줄**: 핵심 해시태그 **정확히 3개** (`#` 형식) → `hashtags`와 동일해야 함. 이후 훅·소개·혜택·감성·CTA·타임라인(스포일러 금지)·구독 멘트 등 구조 지시. **마지막**: 핵심 3개와 겹치지 않는 추가 해시태그만. |
| **pinnedComment** | 고정댓글 3~5줄, 참여 유도 |
| **hashtags** | 핵심 키워드 해시태그 3개만, **한 줄** (예: `#건강정보 #시니어건강 #60대건강`) |
| **uploadTags** | 업로드용 태그 **20~25개**. **hashtags의 3개는 넣지 말 것** (중복 방지 규칙이 system에 반복됨) |

공통 제약(system): **한글만**, 클릭베이트 단어 제외, 타임라인 스포일러 금지, 불법·성인·폭력·담배 키워드 금지.

### 3.3 응답 형식 (모델)

**JSON만** 응답하도록 요구:

```json
{
  "description": "...",
  "pinnedComment": "...",
  "hashtags": "#태그1 #태그2 #태그3",
  "uploadTags": ["태그4", "태그5", "..."]
}
```

### 3.4 코드 후처리 (태그·설명 정리)

1. 응답에서 `{ ... }` 블록을 정규식으로 잡아 `JSON.parse`.
2. **hashtags**에서 `#` 제거·소문자 정규화해 **핵심 태그 최대 3개**(`coreTags`) 추출.
3. **description**: 본문 줄들 중 **첫 줄 제외** 구간에서, 위 `coreTags`가 다시 나오면 제거(중복·오염 방지).
4. **uploadTags**: 배열이면 `#` 제거 후 trim, **`coreTags`와 동일한 태그는 제거**.

JSON 파싱에 실패하면: `description`만 전체 텍스트로, `pinnedComment`/`hashtags`는 빈 문자열, `uploadTags`는 빈 배열로 반환합니다.

## 4. “태그”가 UI에서 의미하는 것

- **설명 첫 줄 + `hashtags` 문자열**: 핵심 3개 해시태그(알고리즘·검색용으로 강조).
- **`uploadTags` 배열**: 유튜브 업로드 시 넣는 태그 리스트(20~25개 지시, 핵심 3개 제외 후처리).

화면에서는 설명란 / 고정댓글 / 해시태그 / **업로드 태그(N개)** 구역으로 나뉘어 보여집니다.
