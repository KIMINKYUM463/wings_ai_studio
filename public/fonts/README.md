# Wings Studio 번들 폰트

설치형(데스크톱)·웹 빌드 시 `public/fonts` 가 그대로 포함되어, PC에 폰트를 따로 설치하지 않아도 썸네일·자막 편집에서 사용할 수 있습니다.

| 파일 | CSS 패밀리명 |
|------|----------------|
| gmarket-sans-bold.ttf | Gmarket Sans Bold |
| gmarket-sans-medium.ttf | Gmarket Sans Medium |
| gmarket-sans-light.ttf | Gmarket Sans Light |
| nanum-barun-gothic.ttf | Nanum Barun Gothic |
| nanum-barun-gothic-bold.ttf | Nanum Barun Gothic Bold |
| nanum-barun-gothic-light.ttf | Nanum Barun Gothic Light |
| nanum-barun-gothic-ultralight.ttf | Nanum Barun Gothic UltraLight |
| gangwon-modu-bold.ttf | Gangwon Education Modu Bold |
| gangwon-modu-light.ttf | Gangwon Education Modu Light |
| gangwon-saeeum.ttf | Gangwon Education Saeeum |
| gangwon-tuntun.ttf | Gangwon Education Tuntun |
| gangwon-hyeonok.ttf | Gangwon Education Hyeonok |
| nanum-handwriting-galmaetgeul.ttf | Nanum Handwriting Galmaetgeul (나눔손글씨 갈맷글) |
| nanum-handwriting-garamyeonkot.ttf | Nanum Handwriting Garam Yeonkot (나눔손글씨 가람연꽃) |
| nanum-handwriting-gangbujang.ttf | Nanum Handwriting Gang Bujangnim (나눔손글씨 강부장님체) |
| cafe24-pro-slim-max.ttf | Cafe24 PRO Slim Max |
| sb-aggro-light.ttf | SB Aggro Light |
| sb-aggro-medium.ttf | SB Aggro Medium |
| sb-aggro-bold.ttf | SB Aggro Bold |
| hs-santokki-regular.ttf | HS Santokki (HS 산토끼) |

각 폰트의 라이선스·상업적 이용 조건은 원 배포처(네이버 나눔, G마켓, 강원교육청, 카페24, 산돌, 네이버 SB 등) 안내를 따릅니다.
