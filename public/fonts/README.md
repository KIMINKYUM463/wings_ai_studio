# Wings Studio 번들 폰트

설치형(데스크톱)·웹 빌드 시 `public/fonts` 가 그대로 포함되어, PC에 폰트를 따로 설치하지 않아도 썸네일·자막 편집에서 사용할 수 있습니다.

OFL 폰트는 소프트웨어에 포함해 재배포할 수 있으나 라이선스 파일(*-OFL.txt)을 함께 배포해야 하고, 폰트 단독 판매는 금지됩니다.
썰쇼핑숏폼 자막 글꼴 목록은 `lib/wings-shopping-v2/templates/fonts.ts` (ASS 는 파일 내부 패밀리명으로 찾음).

각 폰트의 라이선스·상업적 이용 조건은 원 배포처(네이버 나눔, G마켓, 강원교육청, 카페24, 산돌, 네이버 SB 등) 안내를 따릅니다.
